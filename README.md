# FluxFile Marketing Site

A modern animated marketing website for FluxFile, built with React, Vite, Tailwind CSS, and Framer Motion.

## Features

- **Hero Section**: Animated entrance and gradient effects.
- **Live Demo**: Simulates real-time file updates with a pulsing code block.
- **Responsive Design**: Fully responsive navigation and layout.

## Setup & Run

1.  Install dependencies (already done if you see this):
    ```bash
    npm install
    ```
2.  Start the development server:
    ```bash
    npm run dev
    ```
3.  Open the link shown (usually http://localhost:5173).

## Project Structure

- `src/components/`: Reusable UI components.
- `src/App.jsx`: Main page layout.
- `tailwind.config.js`: Theme customization (colors, animations).
